# UoP Department & Society Website Template

A highly reusable, modular PHP template built specifically for University of Peradeniya (UoP) departments, units, and student societies. This template is designed for rapid deployment, utilizing **Tailwind CSS v4** for styling and **PHP Data Objects (PDO)** for secure database management.

Created by [Isuru Etampawala](https://www.linkedin.com/in/isuru-sasanga-etampawala).

## 🌟 Features
* **Centralized Configuration:** Manage all site data, navigation, social links, contact info, and Google Maps URLs from a single `includes/config.php` file.
* **Component-Based UI:** Clean, reusable PHP functions for rendering cards, page headers, and sections without duplicating HTML.
* **Database-Ready:** Includes a dynamic News and Events schema utilizing secure PDO connections.
* **Official UoP Branding:** Pre-configured with UoP Maroon (`#7b1113`) and Gold (`#eab308`), alongside official logo and favicon placeholders.
* **Modern CSS:** Powered by Tailwind CSS v4 for utility-first, responsive design.

## 🛠 Prerequisites
To run this template locally, you will need:
* A local server environment (e.g., **XAMPP**, WAMP, or MAMP) running **PHP 7.4+**.
* **MySQL** or MariaDB.
* **Node.js & npm** (required to compile Tailwind CSS).

## 🚀 Installation & Setup

### 1. Clone the Repository
Clone this repository into your local server's public directory (e.g., `C:\xampp\htdocs\`).
```bash
git clone [https://github.com/yourusername/your-repo-name.git](https://github.com/yourusername/your-repo-name.git) uop-template
cd uop-template
```

### 2. Configure the Base URL

Open `/includes/config.php` and update the `$site_config['base_url']` to match your local folder name.

- If your project is inside `htdocs/uop-template`, set it to: `'/uop-template'`

* If hosting on a live domain root (e.g., `https://cgu.pdn.ac.lk`), set it to an empty string: `''`

### 3. Database Setup

1. Open phpMyAdmin (or your preferred SQL client) and create a new database (e.g., `template_db`).
2. Import the `database.sql` file provided in the root directory to generate the required tables.
3. Update the `db` array in `includes/config.php` with your database credentials.

### 4. Install Tailwind CSS v4

Open your terminal in the project root and install the required Tailwind packages:

```bash
npm install tailwindcss @tailwindcss/cli
```

To start the Tailwind development watcher (which automatically compiles your CSS as you code), leave this command running in your terminal:

```bash
npx @tailwindcss/cli -i ./assets/css/input.css -o ./assets/css/output.css --watch
```

## ⚙️ Configuration Guide

The `includes/config.php` file is the brain of this template. You should rarely need to hardcode text into the HTML.

To update the website's branding, simply modify the `$site_config` array:

```php
$site_config = [
    'name' => 'Department of Computer Science',
    'short_name' => 'DCS',
    'tagline' => 'Innovating the future of computing.',
    'contact' => [
        'address' => 'Faculty of Science, UoP.',
        'email' => 'head@cs.pdn.ac.lk',
        // ...
    ],
    // ...
];
```

*Note: The header navigation links are automatically generated based on the* `nav_links` *array in this file.*

## 🧩 UI Component Library

Instead of writing repetitive HTML, this template uses PHP functions to render consistent UI components. Include the component file at the top of your page to use them.

### 1. Service / Feature Card

Ideal for highlighting specific features, objectives, or services.

```php
require_once 'components/cards/card-service.php';

// render_service_card($title, $description,$icon_svg, $link_url = null,$link_text = "Learn More")
render_service_card(
    "Career Counselling", 
    "Book a one-on-one session.", 
    "<svg>...</svg>", 
    "/services.php"
);
```

### 2. Media Card (News & Events)

Ideal for blog posts or event listings. Automatically falls back to `/assets/images/placeholder.jpg` if no image URL is provided.

```php
require_once 'components/cards/card-media.php';

// render_media_card($title, $description,$image_url, $date_top,$date_bottom, $link_url,$link_text = "Read More")
render_media_card(
    "Annual Hackathon", 
    "Join us for a 24-hour coding challenge.", 
    "", // Leave empty for placeholder
    "Oct", "24", 
    "/event_details.php?id=1"
);
```

### 3. Profile Card (Team Directory)

Automatically falls back to `/assets/images/staff/default-avatar.png` if no image is provided.

```php
require_once 'components/cards/card-profile.php';

// render_profile_card($name, $role,$image_url = "", $phone = null,$email = null)
render_profile_card(
    "Prof. John Doe", 
    "Head of Department", 
    "", // Image URL
    "081 239 XXXX", 
    "john@pdn.ac.lk"
);
```

## 🗄 Database Schema

The included `database.sql` file creates four tables:

1. `events`: Stores event details, dates, and thumbnails.
2. `event_gallery`: Stores multiple images associated with a specific event ID.
3. `news`: Stores news articles and publish dates.
4. `news_gallery`: Stores multiple images associated with a specific news ID.

Connections to this database are securely handled in `includes/db_connect.php` using prepared statements.

## 🎨 Customization

If you are deploying this for a unit that does not use the default UoP Maroon and Gold, you can globally change the theme colors.

Open `assets/css/input.css` and modify the `@theme` variables:

```css
@theme {
  --color-primary: #YOUR_HEX;   /* e.g., Faculty of Science Blue */
  --color-secondary: #YOUR_HEX; 
}
```

After saving, the Tailwind watcher will automatically recompile `output.css` and update the entire site.
